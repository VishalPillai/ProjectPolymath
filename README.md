# Speak Easy Hub

Build me a simple dark mode speaking practice landing page for language learners, with a calm modern editorial feel. The main idea should be super minimal and focused on one action, with lots of breathing room and a warm copper accent against a deep charcoal background. Use a clean sans serif for the UI, and bring in a serif feel for the main practice text so it feels a little more thoughtful and less clinical.

The page should show a quick speaking prompt area, something like off the cuff or deep research, with a small category label, a status like ready, a comfort zone selector, and one clear primary button that says Spin and starts a one minute timer. The button should be a rounded pill with a soft glowing shadow, and the whole experience should feel friendly, practical, and very light. Keep it sparse, elegant, and easy to use, with the emphasis on helping someone think fast and practice speaking out loud.

Use this design system for the visuals: https://gitreverse.com/designs/unprompted-cool
